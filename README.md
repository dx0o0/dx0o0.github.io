## Research

The website presents research in big data governance, data quality management, high-quality data construction for machine learning, and industrial IoT time-series data governance and analytics. It includes academic appointments, education, selected funded projects, recent publications, books, patents, software registrations, awards, academic service, and invited talks.

## Site structure

- `index.html`: detailed bilingual academic homepage.
- `snapshot.html`: concise bilingual profile.
- `styles.css` and `snapshot.css`: responsive styles for the two views.
- `script.js`: Chinese/English switching and the decorative hero animation.
- `assets/profile/xiaoou-ding.jpg`: portrait extracted from the supplied curriculum vitae.

## Local preview

Run a static HTTP server from the repository root:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000/` or `http://localhost:8000/snapshot.html`.

The academic content was compiled from the March 2026 curriculum vitae supplied for this repository. The public pages omit the phone number, date of birth, exact office room, detailed project budgets, and certificate identifiers contained in that document.
